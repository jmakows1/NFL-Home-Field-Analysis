# NFL-Home-Field-Analysis
Code used in project
## Key Findings
- **Historical Baseline:** Home teams win ~57% of the time.
- **The Decline:** Home win margins have dropped from 3+ points to nearly 2 points.
- **The 2020 Anomaly:** Without fans, the home-field advantage nearly vanished (50% win rate).

## Tools Used
- **Python** (Pandas, Matplotlib, Seaborn)
- **Jupyter Notebooks**
- **Kaggle NFL Dataset**
